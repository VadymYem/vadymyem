# 🚀 Над чим я працюю зараз

## 🎙️ OpenVox

<a href="https://github.com/vadymyem/OpenVox">
  <img src="https://img.shields.io/badge/OpenVox-View_Project-6ee7b7?style=for-the-badge&logo=github&logoColor=111827" alt="OpenVox" />
</a>

**OpenVox** — безкоштовна open-source студія для вокалістів, музикантів, викладачів і хорів, яка працює безпосередньо у браузері.

Проєкт об'єднує:

* 🎤 real-time pitch detection;
* 🎼 вокальні вправи;
* 🎹 тренування слуху;
* 🎵 sight singing;
* 🎚️ професійні аудіоінструменти;
* 🎧 backing track practice;
* 🎛️ multitrack mixer;
* 🎻 налаштування музичних інструментів;
* 📊 аналіз голосу;
* 🎶 voice-to-score transcription;
* 📝 нотний редактор;
* 👥 інструменти для хорових репетицій;
* 🔒 local-first обробку аудіо.

Основна філософія OpenVox:

> **Your voice should not need to leave your device to be analyzed.**

**Stack:**

`React` · `TypeScript` · `Vite` · `Web Audio API` · `AudioWorklet` · `WebAssembly` · `IndexedDB` · `PWA`

Код можна досліджувати, покращувати та розвивати разом із community.
